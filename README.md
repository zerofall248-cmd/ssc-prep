# SSC Prep

A mobile-first exam-preparation portal for SSC aspirants, built with Next.js, React, TypeScript and Tailwind CSS.

## Current milestone

The initial homepage uses local mock data only. Authentication, database persistence, payments and official SSC integrations are not configured yet.

## Run locally

1. Install Node.js 20.9 or newer.
2. Run npm install.
3. Run npm run dev.
4. Open http://localhost:3000.

SSC Prep is an independent preparation project and is not affiliated with the Staff Selection Commission. All sample practice listings are illustrative, not official papers or notifications.
